# Faltu: shorts factory

Faceless shorts for YouTube (solo hype, Kratos Playz) and Instagram (@solohype_1), made in code.

- `.claude/skills/faceless-shorts/`: the video skill (styles, scripts, tools)
- `shorts-out/`: finished videos, queues, logs, `FACTORY.md` (the step-by-step), `STYLE-LIBRARY.md`
- `CLAUDE.md`: the owner's mission and rules
