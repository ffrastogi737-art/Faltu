# video-suite: teen video tools, ek jagah

Teeno tools ek hi folder mein, taaki baad mein inhe ek pipeline mein jod sakein. Har tool apne folder mein chalta hai.

| folder | kya karta hai | input | kab use karein |
|---|---|---|---|
| `faceless-shorts/` (= `.claude/skills/faceless-shorts`, symlink) | script se faceless video banata hai: voice, captions, drawn shots, music, effects | sirf topic / script | solo hype, Kratos Playz ke drawn videos (roz ke Shorts + long) |
| `ai-video-editor/` | aapki apni talking-head recording ko cut karta hai (silence, retake), motion graphics, SFX, loudness | aapka video file | jab aap khud camera par bolte hain |
| `clippers/gta6-viral-clipper/` | lamba gameplay / stream video se 20-30 vertical clips chunta hai aur render karta hai | lamba video (apna ya permission wala) | sirf jab hamare paas apna footage ho |
| `clippers/peakcut-clipper/SKILL.md` | upar wale jaisa clip tool, PeakCut engine ke saath (word-bounce captions, animated hook, SFX) | lamba video | reference; engine GitHub se aata hai |

Note: Rockstar ka fan-content niyam: game footage monetized videos mein grey area hai. Kratos Playz ke liye clippers tabhi, jab niyam check ho gaya ho.
