# Jewel Studio (Shri Radha Krishna Jewellers, @shri.radhakrishnajewellers)

One real product photo -> designed post (1080x1350) + 12 s reel (1080x1920) with music.

    python3 jewel-shop/jewel.py <photo> <out_prefix> --title "Rani Haar Set" --sub "Necklace + matching Jhumke" [--price 1299]

Needs Pillow, numpy, scipy, ffmpeg. Photos come from the Drive folder "Jewellery Shop Uploads" (id 14QcH071kSN4x-mI9A-Eu9IMWL8OMC8uw).
Rules: only real photos, always say "1 Gram Gold Plated", never claim real gold, nothing posted before the owner OKs the look.
