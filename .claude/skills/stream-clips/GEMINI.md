# stream-clips

This folder is the **stream-clips** skill: it turns long streams and videos into vertical,
captioned, ready-to-post clips on any topic.

When the user asks to clip a stream, find streams, or make Shorts/TikToks/Reels from a long
video, read `SKILL.md` in this folder and follow it exactly. In Gemini CLI use
`--brain gemini` (or `--brain agent` to pick the moments yourself).
